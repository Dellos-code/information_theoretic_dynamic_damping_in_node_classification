# E1 report — Track-A EDSP vs B0/B1 Track-A baselines (real datasets)

**Scope.** Track-A (labels and graph only, no node features) on the 16 registered
single-label datasets; all official / registered splits (Planetoid public + 10
random, Platonov 10, WikiCS 20, Shchur 10 random, Sampson 18 leave-one-out).
Methods: EDSP-default (zero-tuning default of §2.5), EDSP-tuned (9 validation-
selected configurations), the named variants EDSP-GS / EDSP-damped(0.5) on the
first 3 splits (H7), and the B0/B1 Track-A baselines with equal 9-point grids.

**Provenance (rule R1).** 1,761 run records in `results/runs/e1/` (incl. one
DATASET-STATS record per dataset), all from Actions run
[42214169204](https://github.com/Dellos-code/information_theoretic_dynamic_damping_in_node_classification/actions/runs/42214169204)
on commit 2ff5600 (PR-8). This re-run supersedes the first E1 (runs 42067613272 and
42112122532, commit d0f8bc3 of `main`), because PR-8 added the §5.7 stratified
accuracy and the empirical mixed cells C3c / C3d to every record. EDSP code is
unchanged and every EDSP number is identical to the first E1; baseline numbers
differ by at most 0.4 points (citeseer LGC 68.31 → 68.70), because all baseline
solves are now CG (PR-7b) and validation ties can resolve differently.

Tables: `results/aggregates/e1/E1_SUMMARY.md` (generated by `scripts/aggregate_e1.py`
from those records). Every number below is copied from that file.

## 1. Headline results

EDSP does **not** outperform the label-propagation baselines in the label-only
setting. Against LGC it has no win on any real dataset.

| comparison (real datasets, Wilcoxon over splits, Holm) | win | tie | loss |
|---|---|---|---|
| EDSP-tuned vs LGC | 0 | 4 | 10 |
| EDSP-tuned vs PPR-LP | 1 | 9 | 4 |
| EDSP-tuned vs harmonic (plain) | 4 | 9 | 1 |
| EDSP-tuned vs harmonic + CMN | 2 | 10 | 2 |
| EDSP-tuned vs LinBP-MCE | 10 | 2 | 2 |
| EDSP-tuned vs train prior | 12 | 0 | 2 |

Friedman test over 14 real datasets: p = 2.29e-08; Nemenyi CD = 2.81. Average
ranks: LGC 1.50, harmonic+CMN 3.32, PPR-LP 3.71, **EDSP-tuned 4.14**, harmonic
4.68, **EDSP-default 5.64**, LinBP 6.00, train prior 7.00. EDSP-default is
significantly worse than LGC (rank difference 4.14 > CD); EDSP-tuned vs LGC
(2.64) is not significant at the Nemenyi level, although the per-dataset
Wilcoxon tests show 10 significant losses.

## 3. Where EDSP stands, dataset by dataset (Track-A)

- **Homophilic graphs (Amazon, Coauthor, Cora, CiteSeer):** EDSP ≈ harmonic LP;
  LGC or harmonic+CMN is best by 0.2–1.3 points.
- **Low-label splits (PubMed public, WikiCS):** EDSP-default collapses like plain
  harmonic LP; EDSP-tuned recovers part of it (WikiCS 67.2, PubMed 79.3 mean),
  still below LGC.
- **Strongly heterophilic, many classes (roman-empire, k = 18):** every
  propagation method falls below the majority class (14.0), except LinBP-MCE (27.5),
  which estimates a full compatibility matrix. EDSP-tuned (9.1) mostly picks
  H-LEARNED, which is close to "all edges heterophilic"; the complement operator
  then only says "another class", which is too weak for k = 18. This is the
  setting of H3 (EDSP-fullH), to be tested in E5.
- **Label-uninformative heterophily (squirrel-filtered, chameleon-filtered):**
  nothing beats the majority class on squirrel (35.1); on chameleon LGC is best (36.5) and EDSP is at 30.
- **Calibration:** EDSP's NLL and ECE are worse than those of the best baseline
  on most datasets; on roman-empire EDSP-default is confidently wrong
  (NLL 5.0, ECE 0.47).
- **Signed case study (Sampson, 18 nodes, leave-one-out, excluded from
  statistics):** EDSP with native signs 66.7% = signed vote 66.7%, against 44.4% for
  harmonic/LGC/PPR-LP. Too small to conclude anything, but it is the only
  setting so far where the polarity mechanism carries information.

## 4. What this means for the paper (assessment, not a result)

In the label-only setting on standard benchmarks the method behaves as the
analysis predicted: on unlabelled nodes it is harmonic label propagation, and
leakage-free polarity collapses to the base rate (PR #5 diagnostics), so the
heterophily mechanism adds little. The arenas where EDSP's distinctive
components (per-edge polarity h_ij, edge probabilities p_ij, P_esc) can matter are
native signed and relation-typed graphs (E2, see docs/E2_REPORT.md), native
probabilistic graphs (C4), and the feature-prior track against Correct & Smooth (E3).

On unsigned real graphs EDSP does **not** rescue heterophilic nodes: on every
dataset its low-h accuracy is at or below LGC's. Its low-h / high-h profile is
the harmonic-LP profile, consistent with §4 (leakage-free polarity ≈ base rate).
Contrast E2 (signed graphs), where it does.
