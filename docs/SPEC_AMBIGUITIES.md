# Specification ambiguities

This file records unresolved interpretations without changing the canonical implementation.

| Item | Literal interpretation used | Alternative / follow-up |
|---|---|---|
| Infinite trust | `exp(-inf)=0`, so calibration leaves the input unchanged | Add explicit finite/infinite trust property tests when LabelVault/regimes land |
| Duplicate undirected edges | Every input row is an edge and is expanded in both directions | Dataset loaders must document whether duplicate rows are pre-aggregated |
| Oscillation diagnostic | The implementation records period-2 detection as a diagnostic only; it does not alter `EDSP-canonical` | Named GS and damped variants are reported separately |
| Max-iteration prediction iterate | When a run reaches `max_iter` without convergence, predictions and calibration metrics use the last iterate; the last two iterates are also stored for diagnostics | Pre-registered (docs/PREREGISTRATION.md §2): headline = last iterate; secondary labelled column = mean of the last two iterates whenever a run did not converge |
| Graph canonicalisation (PR-2) | Every loader symmetrises edges, removes self-loops and merges duplicate/reciprocal rows (`edsp.data.graph.canonicalize_edges`); counts are kept in `meta['canonicalization']`. For edge attributes the first occurrence is kept and conflicting merges are counted; signs are summed (H-NATIVE rule §2.3a) | ogbn-proteins: if conflicting reciprocal attributes appear, decide between first/mean/max in PR-4 (P-NATIVE) |
| Planetoid preprocessing (PR-2) | Mirrors torch_geometric `read_planetoid_data`: test rows re-ordered, CiteSeer's 15 test-range gaps padded with zero features and label 0, padded nodes excluded from all splits | — |
| Registry format (PR-2) | `data/REGISTRY.json` instead of `REGISTRY.yaml`: no YAML dependency in the locked environment | Switch to YAML if a YAML parser is added to the lock |
| Sampson (PR-2) | Network `Sampson_T4` (18 novices, directed ±1 arcs) with partition `Sampson_factions_T4` (4 factions) from Pajek ESNA `Sampson.paj`; the Master Prompt's "25 nodes" refers to the unlabelled multi-time network | Owner may prefer another Sampson relation/time slice |
| Label access for dataset statistics (PR-2) | Full-label statistics read labels via `LabelVault.descriptive_labels()`, allowed only from `edsp.data.stats`; they describe datasets and are never inputs to a method | — |
| Constructed benchmark (PR-2) | `minesweeper` (Platonov et al.) is a constructed grid game, not a real network; kept as an established benchmark but flagged | Decided (docs/PREREGISTRATION.md §3): kept, labelled, excluded from real-world aggregates |
| H-NATIVE zero-sum pairs (PR-4) | §2.3a literally: h = 1 iff summed sign < 0, so pairs whose reciprocal signs cancel get h = 0 (count reported in diagnostics) | A "drop conflicting" variant (§2.3a) belongs to the E2 suite |
| H-LEARNED edge representation (PR-4) | Track-B input [x_i, x_j, \|x_i−x_j\|, x_i⊙x_j] as specified; since an undirected edge has no orientation, training uses both orders and prediction averages P(het) over (i,j) and (j,i). Node features with more than 64 dimensions are first reduced by randomized SVD (centred, float32) to keep the design matrix tractable; at most 100,000 train–train edges (seeded subsample) are used for fitting | Raise `max_dim` / `max_train_edges` if an ablation shows they matter |
| H-LEARNED Track-A features (PR-4) | Label-free structural features: log-degree sum and absolute difference, log(1+common neighbours), Jaccard, Adamic-Adar, and Hadamard / absolute-difference products of a 16-dim spectral embedding of D^{-1/2} A D^{-1/2}; neighbourhood-overlap features are skipped above 5M edges | node2vec embeddings (§2.3c) not implemented |
| H-LEARNED decision and confidence (PR-4) | h = 1[P(het) ≥ 0.5] with a class-balanced classifier; P-LEARNED confidence p = max(q, 1−q); l2 ∈ {1e-3, 1e-2, 0.1, 1, 10, 100} (PR-4b; PR-4 used {0.01,…,10}) chosen by ROC-AUC on train–val and val–val edges; if train–train edges contain only one polarity, fall back to H-ALL0 with p = 0.5 and record it | Superseded in PR-4b (next row); train–train edges are not overwritten with their known polarity (literal §2.3c) |
| P-NATIVE string-combined (PR-4) | Prior-corrected noisy-OR with STRING prior 0.041: s'_c = clip((s_c−0.041)/(1−0.041)), s = 1−∏(1−s'_c), p = s + 0.041(1−s) | Prior value and formula TO VERIFY against string-db.org |
| Track-B base predictor (PR-4, revised PR-4b) | Only multinomial logistic regression (numpy/scipy, L-BFGS) is implemented; no feature reduction below 20,000 dims (PR-4 reduced to 256, which weakened the predictor); l2 ∈ {1e-3,…,100} × {standardised, raw features} chosen by validation accuracy, temperature by validation NLL; T_j = τ(ln k − H(prior_j))/ln k | 2-layer MLP and LightGBM base predictors (§2.1) still to add (need dependencies in the lock) |
| Multi-label graphs (PR-4) | `build_inputs` rejects multi-label graphs (ogbn-proteins); they are run per task as binary problems in the E2 suite | — |
| H-LEARNED decision rule (PR-4b) | The class-balanced classifier estimates P(het) under equal class priors; PR-4 thresholded it at 0.5, which under-predicted heterophily on strongly heterophilic graphs (PR #4 comment). Default is now `prior-corrected`: logit q = logit q_raw + log(π/(1−π)), π = heterophily of train–train edges (train labels only), h = 1[q ≥ 0.5], P-LEARNED p = max(q, 1−q). Named options: `val-threshold` (threshold from {0.05,…,0.95} by validation-edge accuracy, a selection step) and `balanced` (PR-4 rule) | Single-class train edges now fall back to H-ALL<that class> instead of H-ALL0 |
| Linear-propagation baselines (PR-5, solver changed in PR-7b) | harmonic, LGC and PPR-LP solve their linear systems to convergence (PR-5: sparse LU; PR-7b: Jacobi-preconditioned CG with rtol 1e-10 on the equivalent SPD systems, LU fallback — identical predictions on PubMed, max |ΔP| < 1e-8) instead of truncated iterations: the Jacobi iteration of the harmonic function did not converge in 1,000 steps on the Planetoid public splits | — |
| Harmonic LP variants (PR-5) | Both the plain harmonic solution and class mass normalisation (CMN, Zhu et al. 2003) are reported: plain harmonic collapses to the majority-of-propagated-mass class on the PubMed public split, CMN does not | The REPORTED "LP" numbers (Yang et al. 2016) do not state which variant was used |
| LinBP beliefs (PR-5) | LinBP* without echo cancellation, ε = scale/(ρ(W)ρ(Ĥ)); centred beliefs are mapped to probabilities by adding 1/k, clipping at 0 and renormalising (needed for NLL/ECE) | DCE compatibility estimation still to add |
| Correct & Smooth (PR-5) | Symmetric-normalised adjacency in both steps, iterated to convergence (tol 1e-6) rather than a fixed 50 layers; autoscale correction; train nodes reset to their one-hot labels before smoothing | PyG `CorrectAndSmooth` parity not run (PyG not in the lock) |
| Tuning budgets in E1 (PR-7) | Rule R6 is implemented as equal grid sizes: EDSP-tuned, LGC, PPR-LP, LinBP and C&S each get 9 validation-selected configurations; harmonic LP has no hyper-parameter. EDSP-tuned grid: p0 ∈ {0.1, 0.5, 0.9} × h ∈ {H-TRAINONLY(b1) (H-NATIVE on signed graphs), H-LEARNED, H-ALL1}, T_L = ∞. Selection uses the validation value of the dataset's headline metric (accuracy or ROC-AUC) | Optuna TPE with 50 trials (§5.3) replaces grids when Track-B / GNN baselines enter (E3) |
| "Fraction of oscillating nodes" in H7 (PR-7) | Measured as the fraction of nodes whose L1 change between the last two iterates is ≥ ε; for converged runs it is 0 | — |
| H7(c) scope (PR-7) | GS (id order, at most 300 sweeps) vs damped(0.5) distance is computed on the first 3 splits of every dataset (GS is a Python loop over nodes) | Extend to all splits if compute allows |
| Relation-typed fraud graphs (PR-3) | YelpChi (R-U-R, R-T-R, R-S-R) and Amazon (U-P-U, U-S-U, U-V-U) from the CARE-GNN `.mat` files; an undirected pair present in several relations is one edge whose `edge_relation` is the bitmask of its relations, so H-RELATION learns one polarity per relation *combination* (7 at most) | One edge per (pair, relation) — a multigraph — would let EDSP's noisy-OR combine relations; not done because the core takes simple graphs |
| Amazon unlabelled prefix (PR-3) | The first 3,305 Amazon nodes are treated as unlabelled (label −1), as in the CARE-GNN / PC-GNN / BWGNN code; they stay in the graph, are excluded from every split and from homophily statistics (`edge_homophily`, `local_homophily` skip labels < 0) | TO VERIFY against the CARE-GNN data README |
| Fraud splits (PR-3) | 10 stratified random 40/20/40 splits (seeds 0–9), headline ROC-AUC | Some papers use 1%/40% training fractions; add as a label-rate ablation in E6 |
| Signed graphs with node labels (PR-3) | Convention of Mercado et al. (ECML-PKDD 2019): keep labelled nodes only, then the largest connected component; reciprocal / duplicate signs are summed (zero-sum pairs keep an edge with sign 0, H-NATIVE treats them as homophilic, see the PR-4 row); 10 stratified 60/20/20 splits | Mercado et al. report label-rate sweeps; add in E6 |
| wiki-RfA / wiki-Elec labels (PR-3) | Label = outcome of the candidate's (last) election; votes are directed voter → candidate, neutral votes dropped. Because the label is decided by the incoming votes (Master Prompt §3.1 C5.3 leakage), both are reported as **case studies** next to the mandatory `signed_vote` baseline and are excluded from ranks and win/tie/loss totals (scripts/aggregate_e1.py `EXCLUDED_FROM_RANKS`) | — |
| Signed label-propagation baseline (PR-3) | `signed_lgc`: label spreading with the signed normalised adjacency Dbar^-1/2 A_s Dbar^-1/2 on centred one-hot labels (Kunegis et al. 2010; the signed-Laplacian LP family of Mercado et al. 2019), 9-point α grid as LGC. Mercado's GL (diffuse-interface) method itself is not implemented yet | Port GL from melopeo/GL (MATLAB) in a later PR |
| Stratified accuracy (PR-3, Master Prompt §5.7; bins corrected in PR-8) | Each test node is binned by its local homophily over all labelled neighbours (10 bins of width 0.1 as §5.7 states — PR-3 had 5 — plus 11 logarithmic degree bins; descriptive labels via `edsp.data.stats.local_homophily_bins`); runners store per-bin counts and correct counts in every record; bins are never method inputs | — |
| PERTURBED-REAL mixing sweep (PR-8) | Not in the Master Prompt's §5.5 list (which perturbs labels, p and h but not the label pattern of the edges); added on the owner's request. Edges of a real graph are re-drawn per edge with an anchor-kept, degree-proportional partner from the anchor's class (prob. h[anchor]) or from the heterophilic target; strata keep heterogeneous patterns local; see `edsp/data/perturb.py` and PREREGISTRATION A2 | Configuration-model rewiring with exact degree preservation; a Track-B variant (features kept) |
| Re-wired graphs and connectivity (PR-8) | Re-wiring is not connectivity-preserving: e.g. Cora goes from 78 components to ≈ 170–220; component counts are stored in every MIX DATASET-STATS record, and LP methods give uncovered components the train prior / uniform as in E1 | — |
